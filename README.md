# Vitrine Certa

Painel gratuito para organizar uma operação de afiliados no Brasil, com Shopee e Mercado Livre.

## Incluído
- Painel de cliques, vendas, comissão e conversão.
- Cadastro e edição de produtos, preço conferido, plataforma e links de afiliado.
- Calendário editorial inicial de 30 dias com status.
- Roteiros de vídeos, legendas, stories, comparativos e aviso de afiliado.
- Exportação CSV.
- Armazenamento local no navegador, sem servidor, conta ou API paga.

## Publicar pelo GitHub Pages
1. Abra **Settings → Pages** neste repositório.
2. Em **Build and deployment**, escolha **Deploy from a branch**.
3. Selecione a branch **main** e a pasta **/(root)** e salve.
4. Aguarde o GitHub publicar o endereço exibido nessa tela.

Também é possível abrir o arquivo `index.html` diretamente no navegador.

## Configuração e uso
1. Cadastre links de afiliado gerados nas suas próprias contas.
2. Antes de divulgar, confirme preço final com frete, estoque, vendedor, avaliações, prazo, devolução e comissão nas plataformas.
3. Atualize manualmente os resultados com os dados oficiais.
4. Exporte o CSV periodicamente para manter uma cópia de segurança.

## Limitações importantes
Os seis produtos iniciais são apenas ideias para pesquisa, não ofertas verificadas. O painel não consulta marketplaces, não faz scraping, não gera links, não acessa contas e não sincroniza pedidos. Preços, comissões e estoque não são inventados: precisam ser preenchidos após conferência.

Os dados ficam no armazenamento local do navegador e não são sincronizados entre dispositivos. Limpar os dados do navegador pode apagá-los. Use a exportação CSV para backup.

Identifique conteúdos com link de afiliado. Exemplo: “Este conteúdo contém link de afiliado. Posso receber comissão se você comprar por ele, sem custo adicional para você.”
